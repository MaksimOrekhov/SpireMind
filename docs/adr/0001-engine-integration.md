# ADR 0001. Нативный адаптер Instinct

**Принято для SM-01.**

SM-01 должен получить проверяемые рекомендации в трёх контекстах без установленной игры. Штатный Rust-пример `play` подходит для сравнения и оценки целых забегов. Он выводит итог по seed и не предоставляет контракт с легальными действиями, привязкой экземпляров и оценками для каждой позиции. `SimAdvisor` умеет возвращать рекомендации модификации игры, но принимает её wire-формат, поддерживает переключение на search и требует отдельно контролировать конфигурацию модели и режим обмена. Python bindings используют тот же движок и полезны для обучения, но требуют отдельного интерпретатора и сборки PyO3.

SpireMind связывается с `sts2-e2e`, `sts2-core` и `sts2-wire` из закреплённого публичного checkout. `E2eEnv` поставляет решения с легальными действиями и классами. `encode_for` и `E2eNet::try_logits` выполняют нативный inference. Адаптер обнуляет колонки прогноза будущих намерений перед forward pass. `contract.rs` сохраняет реальные индексы upstream и сортирует классы по полученным логитам. Состояние хранится только в симуляторе и читается приложением в текущей позиции.

Используем официальный специализированный Ironclad 9.0B EMA 0.999 для `v0.111.0`. Ревизия кода, хеш веса и профиль наблюдения — разные части provenance. Файлы модели задаются данными в `pins/instinct.json`. Добавлять второй чекпойнт имеет смысл после проверки формата и разметки входных данных. Дальнейшее обучение может использовать `.pt` и upstream trainer, сохраняя отдельную запись следующего экспорта `.e2ew` и независимый benchmark.

Путь `.local/upstream` держит источники и их MIT-уведомления вне истории SpireMind. `setup.py` закрепляет checkout, `build.rs` проверяет ревизию, `Cargo.lock` определяет точные версии зависимостей. Такой адаптер зависит от публичных типов конкретной ревизии, поэтому при обновлении надо повторить тесты схемы, проверки наблюдения и сравнение на тех же состояниях. Совместимость live-версии игры рассматривается отдельно. [Исследование upstream](../research/upstream.md)
