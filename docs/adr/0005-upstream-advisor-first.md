# ADR 0005. Нативный Advisor как основа боевой интеграции

Решение уточняет [ADR 0004](0004-combat-observation-coverage.md). Строгий адаптер A и его тесты остаются эталоном. Расширение его таблиц отдельных механик прекращено.

**GO для следующего прототипа на нативном upstream. SM-02 остаётся PARTIAL.** На новых 4 374 позициях B прошёл проверку на 98,5%, C и его wire-проверка — на 100%, строгий A — на 23,0%. На прежней широкой панели wire-проверка C потеряла 10 из 4 333 позиций. Семантика транспорта требует отдельной проверки на реальном producer. Доступ к внутренним полям в игре требует предварительного согласования владельца. Допуск в production требует результатов live-проверки.

| Путь | Назначение | Условие дальнейшей работы |
| --- | --- | --- |
| A, строгая реконструкция из публичного наблюдения | Регрессионный эталон легальности, целей и маскированного inference | Хранить отдельно от новых экспериментов и сохранять прежние знаменатели. |
| B, штатный InstinctAdvisor и зеркала | Референс для сравнения входов, следования действиям и формы ответа | Формат исходного мода шире действующей политики SpireMind. Доступ к фактическим RNG и порядку добора исключает перенос B в production в таком виде. |
| C, перенос текущего боя с очищенным будущим | Кандидат на интеграцию через существующий wire и нативный encoder | Нужны отдельное решение владельца о допустимых внутренних параметрах, доказанный producer реальных текущих полей и проверка штатного соединения с игрой. |

Минимальная интеграция начинается с одного стабильного боевого кадра. Producer передаёт версию и идентификатор позиции, явно разрешённые текущие параметры, состав руки и индексы целей. Входная граница нормализует текущий нативный wire и исключает фактические RNG, скрытый порядок добора, будущие комнаты и подготовленные намерения. Rust переиспользует существующие `board` / `graft` / `CombatMirror` там, где подтверждён их контракт, и один вызов нативной политики из C. Проверка сравнивает полную легальность с producer, выдаёт совет только для действующей позиции и снимает его при изменении или обрыве соединения.

Переподключение начинает с нового подтверждённого кадра. Повторное использование зеркала в production имеет смысл только с проверяемой полнотой событий и идентификаторами экземпляров. У штатного зеркала Observe есть восстановление, перенос скрытых счётчиков и догадки по цели. Для интеграции нужен доступ к проверяемой части этих механизмов без переноса неизвестного состояния из прежней сессии. Первый эксперимент можно провести без переноса зеркала между запросами и сверить результат с B, C и кадрами реальной игры до выбора постоянной схемы.

Greedy-план B, fallback из `serve`, автоматические действия и запись в игровые файлы не входят в этот путь. Авторитетные логиты и вероятности остаются выходом закреплённого encoder и checkpoint.
