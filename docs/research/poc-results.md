# SM-01. Результаты PoC

**Решение для ревью — GO по офлайн-feasibility.** Публичный чекпойнт Instinct выполнен нативным движком на всех трёх типах позиции. Live-совместимость остаётся предметом SM-02.

## Среда и команды

27 ноября 2026 года. Windows x64, AMD Ryzen 5 7600X, 6 ядер / 12 логических процессоров. Rust `1.99.1` MSVC, Python `3.12.10` для setup. Release-сборка, CPU, бенчмарк с одним потоком inference. Spire Mentor `a7d5f4d2507afbc5db9a13879c9da77faff4a7e7`, модель `ironclad_e2e_d9000_ema0999.e2ew` из `weights-2026-11-23`, игра `v0.111.0`, Ironclad A10. SHA‑256 совпал с pin. [Ревизии и лицензии](upstream.md)

```powershell
python scripts/setup.py
cargo fmt --check
cargo clippy --release --locked --offline --all-targets -- -D warnings
cargo build --release --locked --offline
cargo test --release --locked --offline
cargo test --release --locked --offline model_smoke -- --ignored --nocapture
.\target\release\spiremind.exe recommend combat --seed 160000008
.\target\release\spiremind.exe recommend card-reward --seed 160000000
.\target\release\spiremind.exe recommend map --seed 160000000
.\target\release\spiremind.exe benchmark --runs 10 --timeout-seconds 120
```

Для первой сборки уберите `--offline`, пока Cargo не заполнит локальный кэш. Локально успешно выполнены форматирование, Clippy, сборка, шесть проверок без весов и отдельный smoke с реальными весами. Обычная команда тестов отмечает `model_smoke` как ignored, вторая выполняет его явно. Установка проверена с повторной загрузкой веса через `setup.py`.

В полном наборе `sts2-e2e` выполнилось 70 проверок, включая 62 библиотечные. Три паритетных теста upstream вернулись досрочно с `SKIP` из-за отсутствия экспортированных Python fixtures, хотя harness пометил их `ok`. Один пример документации помечен `ignored`. Для штатной проверки той же модели с Python-fixtures можно использовать следующий upstream-путь. Экспорт и паритет с PyTorch локально не запускались.

```powershell
$project = (Get-Location).Path
$checkpoint = Join-Path $project '.local/weights/ironclad_e2e_d9000_ema0999.pt'
curl.exe --fail --location 'https://github.com/tfriedel/spire-mentor/releases/download/weights-2026-11-23/ironclad_e2e_d9000_ema0999.pt' --output $checkpoint
if ((Get-FileHash -Algorithm SHA256 $checkpoint).Hash.ToLowerInvariant() -ne 'b991cb9ad6b380f7894dd6b86b2f375be0fe305948bda7f2f3c0ab4e21e25220') { throw 'Checkpoint SHA-256 mismatch' }
$env:E2E_WEIGHTS = Join-Path $project '.local/weights/ironclad_e2e_d9000_ema0999.e2ew'
$env:E2E_FIXTURES = Join-Path $project '.local/e2e-fixtures'
Set-Location .local/upstream/sts2-pycli
uv python install 3.13
uv sync --locked
$env:PYTHONPATH = 'python'
uv run --locked python -m ppo.e2e.export_wb fixtures $checkpoint $env:E2E_FIXTURES 160000008
Set-Location ../sts2-rs
cargo +1.99.1 test --locked -p sts2-e2e --release -- --nocapture
Set-Location $project
```

На собранном CLI проверены ошибки `missing_weights` и `incompatible_game_version` с кодом 1. Бенчмарк с `--timeout-seconds 1` вернул частичный JSON с одним прерванным забегом, девятью незапущенными и кодом 1. Лимит проверяется между решениями симулятора и покрывает всю панель после загрузки модели. За один вызов симулятора или forward pass таймер может выйти за установленный порог.

## Реальные рекомендации

Позиции воспроизводятся из настоящих `E2eEnv` состояний с закреплёнными seed. `recommend` обходит предыдущие решения моделью в офлайн-симуляторе. В тесте seed `160000008` каждый результат сравнивался с `E2eNet::act_greedy` на идентичной позиции. Для трёх проверенных позиций первый класс совпал и со штатным encoder без маски, хотя masked и unmasked combat row различались.

| Контекст | Состояние smoke | Легальные действия | Первый выбор в обеих реализациях |
| --- | --- | ---: | --- |
| Бой | `sim:160000008:4` | 12 | Strike Ironclad, слот руки 0, экземпляр 11, цель TwigSlimeS с индексом 0 и ID 2. Доступны три индекса целей и `end_turn`. |
| Карточная награда | `sim:160000008:1` | 4 | Patter, индекс 0, среди предложений есть skip. После первого боя в `sim:160000000:16` модель выбрала Taunt, skip также присутствует. |
| Карта | `sim:160000008:3` | 4 | Строка 1, колонка 4. На другом seed тест сопоставляет весь список ходов с доступными рёбрами от стартового узла. |

Тест также подтвердил неизменность policy row после перетасовки неизвестного порядка добора и замены RNG-курсоров в бою. Для награды и карты строка совпала после замены поля seed и удаления очередей будущих событий, элит и рядовых встреч. Эти проверки используют полноценные состояния симулятора и реальные тензоры модели.

## Бенчмарк

Фиксированная последовательность `160000000`–`160000009`, лимит 120 секунд. Завершено 10 из 10, побед 9, ошибок, caps и тайм-аутов 0. Обработано 7 775 решений за 65,54 с. Seed `160000001` завершился поражением. Выборка проверяет работу выбранной связки и не даёт статистической оценки её силы.

Время forward измеряется после токенизации. Время панели включает симуляцию и токенизацию. В отдельных CLI-запусках forward занял 4,46 мс для боя с тремя целями, 2,74 мс для награды и 7,59 мс для стартовой карты. Время загрузки модели, проход предыдущих решений и сериализация отчёта в эти цифры не входят.

## Ограничения и SM-02

- CLI принимает симуляторный seed и один из трёх контекстов. Позиции с единственным классом upstream пропускает как вынужденные. При отсутствии подходящей позиции до конца забега команда возвращает `state_unavailable`.
- Точность симуляции в живой игре, совместимость с другими версиями игры и инварианты всех механик не проверялись. CI проверяет Windows и macOS без Steam, а реальная модель тестируется отдельно на Windows.
- Маска прогноза меняет входные данные для боевого хода. Для ревью live-моста сохраните несколько реальных наблюдений с дубликатами карт, разными целями и устаревающими ID. Сравните доступные действия, поля наблюдения и выбранные экземпляры. Согласуйте целевую live-версию и отдельно проверьте её связку с моделью перед началом работ.
