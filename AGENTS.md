# Работа со SpireMind

- Windows — основная платформа для разработки и будущей интеграции с игрой. Поддерживайте офлайн-сборку и тесты на macOS, когда это позволяет upstream.
- Используйте исходные Rust-симулятор, encoder и нативный forward pass Instinct. Проверяйте изменения игровых правил через upstream. Любое изменение ревизии или чекпойнта требует обновления pin, проверки лицензии, реальных smoke и сравнительного бенчмарка.
- Рекомендации строятся для одиночного забега по наблюдаемым данным. В live-адаптере разрешены только чтение состояния и выдача совета. Игровые команды, скрытый RNG и неизвестный порядок добора исключены. Офлайн-прогон может применять действия к собственному симулятору.
- Формат результата должен отличать логит, вероятность выбора и вероятность победы. Сохраняйте идентификаторы позиции, экземпляра карты, цели и модели. Отражайте ошибки, пропуски и ограничения без подмены реального inference.
- Запускайте `cargo fmt --check`, `cargo clippy --release --locked --all-targets -- -D warnings`, `cargo build --release --locked` и `cargo test --release --locked`. С весами отдельно запускайте `cargo test --release --locked model_smoke -- --ignored --nocapture`. `cargo fmt` без `--all` форматирует только SpireMind и не затрагивает закреплённые path dependencies.
- Не включайте в Git веса, игровые файлы, декомпиляцию, извлечённые ассеты или сырые live-снимки. Сохраняйте уведомления лицензий. Итоги проверок без локальных путей записывайте в `docs/research/`.
- Будущий UI использует Vue 3, TypeScript, Composition API и `<script setup>` без точек с запятой. Добавляйте новые компоненты и зависимости при наличии задачи и обоснования.
